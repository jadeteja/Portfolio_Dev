## 🚀 Quick Start

### 1. Backend (Spring Boot 3.x / Java 21)
```bash
cd backend
mvn test
mvn spring-boot:run
```
- API Base: `http://localhost:8080/api/v1`
- Actuator Health: `http://localhost:8080/actuator/health`
- Default Admin: `jade.teja@gmail.com` / `Admin@JadeTeja2026!`

### 2. Frontend (Next.js 15 App Router)
```bash
cd frontend
npm install
npm run dev
```
- Public Website: `http://localhost:3000`
- Admin Console: `http://localhost:3000/admin/login`
